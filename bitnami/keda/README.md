# Bitnami Secure Images Helm chart for KEDA

KEDA is a Kubernetes-based event-driven autoscaler that scales any workload based on the volume of events it needs to process.

[Overview of KEDA](https://github.com/kedacore/keda)

This Helm chart is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
